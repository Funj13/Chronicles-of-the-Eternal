## 📜 Sobre o Projeto
**Chronicles of the Eternal** é um RPG de ação em terceira pessoa com estilo visual inspirado em animes, imersão profunda e uma narrativa focada em uma civilização superdesenvolvida. 

O projeto nasceu originalmente na Godot Engine 4, onde toda a lógica inicial de inventário, movimentação e combate básico foi estruturada. Com o upgrade de hardware e novos objetivos de aprendizado profissional, o desenvolvimento foi **migrado definitivamente para a Unreal Engine 5**, visando explorar o poder do Blueprint/C++, sistemas de animação avançados e gráficos de nova geração.

Este repositório funciona como o nosso **Devlog (Diário de Desenvolvimento)** oficial.

---

## 🔄 A Grande Migração (Godot ➡️ UE5)
Para quem acompanhou o início do projeto, a versão feita na Godot 4 alcançou marcos importantes na fase Alpha (`v6.8-Alpha`). Embora o código antigo tenha sido removido da branch principal para mantermos o repositório limpo, o histórico e o aprendizado servem de fundação para os novos sistemas:

### 🗃️ O que já havia sido validado na Godot:
* **Inventory UI 2.0:** Sistema de inventário em grade responsivo com estética *Tech-Ruins* e painel de detalhes dinâmico.
* **Mecânicas de Loot:** Física de drop de itens no mundo 3D, baús funcionais e empilhamento (*stacking*) de consumíveis.
* **Combate Reativo:** Sistema de equipamentos com armas nas costas/mãos, além de IA básica de perseguição de inimigos usando modelos VRoid (Mixamo).

## 🚀 Novo Roadmap (Unreal Engine 5)

O projeto foi reiniciado do zero na UE5. Os objetivos atuais estão focados em reconstruir o *Core* do jogo:

- [ X ] Configuração do Enhanced Input System (Movimentação fluida em 3ª pessoa)
- [ X ] Configuração do esqueleto e retargeting de animações para o estilo Anime
- [ ] Implementação da base do sistema de combate via Blueprints/C++
- [ ] Reestruturação do Sistema de Inventário Avançado
- [ ] Criação dos primeiros protótipos de mapa e ambientação 3D

## 🛠️ Tecnologias Atuais
* **Engine:** Unreal Engine 5 (UE5)
* **Linguagem Principal:** Blueprints / C++
* **Modelagem & Assets:** Blender / Prototipagem 3D
* **Ambiente de Dev:** Linux (Arch Linux) e Windows 11
* **Controle de Versão:** Git & GitHub

### 🖥️ Especificações do Setup de Desenvolvimento
* **Processador (CPU):** Intel Core i5-12600K
* **Memória RAM:** 32 GB DDR4 (2x16GB) @ 3200MHz
* **Armazenamento:** SSD NVMe M.2 de 512GB
* **Placa de Vídeo (GPU):** AMD Radeon RX 590 GME (8GB VRAM)
